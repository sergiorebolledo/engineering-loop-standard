# Examples

Worked examples of the Engineering Loop Standard applied to a real,
working project — not just the bare output of `engineering-loop init`.

| Example | What it shows |
|---|---|
| [todo-api/](todo-api/) | A minimal, zero-dependency Node.js REST API with tests, hand-tuned `engineering-loop.json`, and filled-in `docs/memory/`. |

Each example is standalone — its own `package.json`, its own tests, own
README. None of them are part of the root npm workspace.
